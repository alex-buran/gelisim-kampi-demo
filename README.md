# Gelişim Kampı · Termal İnziva — Retreat Landing Page (Demo)

A single-page landing site for a wellness & thermal retreat at a spa hotel in
Çeşme. Editorial layout with a deep-petrol palette, Fraunces + Jost typography,
a photographic graded hero with a rotating seal, scroll-reveal motion, a
scroll-snap venue slider, a masonry memories gallery, a card-based pricing
section, and a participant registration form.

> **Sanitized portfolio demo.** Live payment links, the form-submission key,
> and real contact / agency details have been removed or replaced with
> placeholders. The registration form is a no-op in this demo.

## Tech

- One self-contained `index.html` — no build step, no dependencies
- Vanilla HTML / CSS / JavaScript
- Google Fonts (Fraunces, Jost), `IntersectionObserver` reveals, scroll-snap slider
- Fully responsive · alternating light/dark sections · `prefers-reduced-motion` aware
